# How this design system was made

Notes from when the system was created (2026-10-05), kept so later changes know what it was built from.

- **Concept:** a hardware researcher's lab notebook: graphite and paper, one amber accent, and teal for code and focus outlines.
- **Sources:** built from public profile research only: github.com/rickmark (with `apple-knowledge` and `chainfix` pinned, and the hack-different org), the LinkedIn profile, and press coverage of the T2 research (9to5Mac, The Register). blog.rickmark.me couldn't be loaded at the time, and no existing logo or branding was found, so none of the colours or fonts come from an earlier site.
- **Contents:** 9 colours with light and dark values (every text colour checked for WCAG AA in both), IBM Plex Sans and Mono in 7 text styles, 4 spacing steps on an 8px grid, 3 corner radii, a brand book README, and a cover.

## Open items

- **No logo:** the wordmark is the name in plain type.
- **No components:** no buttons, cards or nav are defined in the system itself (the site's CSS implements its own).
- **Placeholder tagline:** "notes from the bench" on the cover is a placeholder.
